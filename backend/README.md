# 📚 Каталог навчальних ресурсів

> Веб-застосунок для управління каталогом навчальних ресурсів з рейтингом, коментарями та фільтрацією.

**Варіант 5** — лабораторна робота з дисципліни "Веб-програмування"

---

## 🚀 Як запустити

### Варіант 1 — Просто відкрити файл
```
frontend/index.html — відкрийте у браузері
```

### Варіант 2 — Через Live Server (VS Code)
1. Встановіть розширення **Live Server**
2. Клацніть правою кнопкою на `index.html` → **Open with Live Server**

### Варіант 3 — Python HTTP сервер
```bash
cd frontend
python -m http.server 3000
# Відкрийте http://localhost:3000
```

## 🏗️ Поля сутності «Ресурс»

| Поле       | Тип    | Валідація             |
|------------|--------|-----------------------|
| `id`       | Number | авто-інкремент        |
| `title`    | String | обов'язкове, мін. 2 символи |
| `url`      | String | обов'язкове, формат URL |
| `category` | Enum   | обов'язкове           |
| `rating`   | Number | обов'язкове, 1–5      |
| `comment`  | String | необов'язкове         |
